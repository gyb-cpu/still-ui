# Site header

A sticky website header that turns solid on scroll, with a gliding active link, mega menu panels, and a mobile sheet.

**Type:** block  
**Id:** `site-header`

## When to use it

Use this block when you need a complete Site header surface: it composes the components it needs and is meant to be dropped into a page.

## Install

```bash
npx shadcn@latest add @still/site-header
```

```tsx
import { ArcMark } from "registry/blocks/site-header/site-header";

export function Example() {
  return <ArcMark />;
}
```
