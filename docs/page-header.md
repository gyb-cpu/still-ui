# Page header

A project page header that folds into a compact bar as you scroll, with tabs whose counts roll.

**Type:** block  
**Id:** `page-header`

## When to use it

Use this block when you need a complete Page header surface: it composes the components it needs and is meant to be dropped into a page.

## Install

```bash
npx shadcn@latest add @still/page-header
```

```tsx
import { PageHeader } from "registry/blocks/page-header/page-header";

export function Example() {
  return <PageHeader />;
}
```
