# Contact section

A validated contact form that morphs into a confirmation, support channels, and office cards with local times.

**Type:** block  
**Id:** `contact-section`

## When to use it

Use this block when you need a complete Contact section surface: it composes the components it needs and is meant to be dropped into a page.

## Install

```bash
npx shadcn@latest add @still/contact-section
```

```tsx
import { contactExampleChannels } from "@/components/still/blocks/contact-section/contact-section";

export function Example() {
  return <contactExampleChannels />;
}
```
