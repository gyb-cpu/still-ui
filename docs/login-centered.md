# Centered login

A passkey-first login card on a quiet ring backdrop that morphs through email and code.

**Type:** block  
**Id:** `login-centered`

## When to use it

Use this block when you need a complete Centered login surface: it composes the components it needs and is meant to be dropped into a page.

## Install

```bash
npx shadcn@latest add @still/login-centered
```

```tsx
import { LoginCentered } from "registry/blocks/login-centered/login-centered";

export function Example() {
  return <LoginCentered />;
}
```
