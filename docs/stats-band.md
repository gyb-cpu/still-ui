# Stats band

Headline numbers that count up in view, each with a tiny visual that proves it and a context line on hover, plain or in a hairline grid.

**Type:** block  
**Id:** `stats-band`

## When to use it

Use this block when you need a complete Stats band surface: it composes the components it needs and is meant to be dropped into a page.
