# Site footer

A website footer with link columns and newsletter, a minimal layout, and a large fading Arc mark.

**Type:** block  
**Id:** `site-footer`

## When to use it

Use this block when you need a complete Site footer surface: it composes the components it needs and is meant to be dropped into a page.

## Install

```bash
npx shadcn@latest add @still/site-footer
```
