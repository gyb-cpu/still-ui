# Sign in

A sign in card that morphs from email to a six digit code to your account.

**Type:** block  
**Id:** `sign-in`

## When to use it

Use this block when you need a complete Sign in surface: it composes the components it needs and is meant to be dropped into a page.

## Install

```bash
npx shadcn@latest add @still/sign-in
```

```tsx
import { SignIn } from "registry/blocks/sign-in/sign-in";

export function Example() {
  return <SignIn />;
}
```
