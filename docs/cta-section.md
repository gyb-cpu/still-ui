# CTA section

A call to action as a centered closing section, a split beside a setup card that completes itself, or a dismissible banner.

**Type:** block  
**Id:** `cta-section`

## When to use it

Use this block when you need a complete CTA section surface: it composes the components it needs and is meant to be dropped into a page.

## Install

```bash
npx shadcn@latest add @still/cta-section
```
