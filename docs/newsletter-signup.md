# Newsletter signup

An email signup framed by a stack of past issues; subscribing drops the next issue, addressed to you, onto the front.

**Type:** block  
**Id:** `newsletter-signup`

## When to use it

Use this block when you need a complete Newsletter signup surface: it composes the components it needs and is meant to be dropped into a page.

## Install

```bash
npx shadcn@latest add @still/newsletter-signup
```

```tsx
import { NewsletterSignup } from "registry/blocks/newsletter-signup/newsletter-signup";

export function Example() {
  return <NewsletterSignup />;
}
```
