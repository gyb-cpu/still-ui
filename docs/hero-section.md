# Hero section

Three full screen SaaS heroes: a live dashboard rising from the bottom edge over a drifting mesh, a workflow graph that routes sample events node by node, and editorial type over a mesh gradient.

**Type:** block  
**Id:** `hero-section`

## When to use it

Use this block when you need a complete Hero section surface: it composes the components it needs and is meant to be dropped into a page.

## Install

```bash
npx shadcn@latest add @still/hero-section
```

```tsx
import { HeroSection } from "@/components/still/blocks/hero-section/hero-section";

export function Example() {
  return <HeroSection />;
}
```
